# Steam 时间球 × 拾刻工作台

把“完成每天的事情”和“游戏时间”联系起来的个人管理小工具。

在拾刻工作台写下任务、设置奖励分钟数，完成任务后赚取游戏额度；Windows 桌面的时间球自动统计 Steam 游戏时长，显示剩余额度，并在超时后提醒结束游戏。

**快速开始：完整解压 → 双击 SteamTimeBall.exe → 单击悬浮球打开工作台。**

## 1. 两种使用方式

| 模式 | 适合谁 | 游戏额度 |
| --- | --- | --- |
| 独立计时 | 先体验工具，暂时不连接网站 | 每日固定 90 分钟 |
| 工作台联动 | 已获得网站访问权限，并完成电脑配对 | 当天完成任务赚取的分钟数，最多 90 分钟 |

独立模式不需要登录网站。右键悬浮球，选择“游戏统计与设置”即可使用本地功能。

**当前分享的是客户端，不是网站访问许可证。** 工作台目前为私人访问；朋友需要先联系站点所有者，用本人登录 ChatGPT 的邮箱获得邀请。没有邀请时，打不开工作台不代表客户端损坏。

## 2. 运行要求与文件

- 64 位 Windows 10 / 11。
- .NET Framework 4.6.2 或更高版本。
- Microsoft Edge WebView2 Evergreen Runtime，用于内嵌工作台。若组件启动失败，请从[微软官方页面](https://developer.microsoft.com/microsoft-edge/webview2/)安装运行时。
- 游戏计时在本机运行；网站、登录和跨设备同步需要联网，不使用独立的 AI API Key，也不会持续调用 AI。

请先把 ZIP **完整解压到可写入的文件夹**。不要在压缩包里直接运行，也不要只复制 EXE。以下文件应在同一个文件夹：

```text
SteamTimeBall.exe
Microsoft.Web.WebView2.Core.dll
Microsoft.Web.WebView2.WinForms.dll
WebView2Loader.dll
WebView2-LICENSE.txt
WebView2-NOTICE.txt
README.md
README.txt
```

程序包不包含完整浏览器运行时，因此体积较小。首次运行后会自动创建自己的 `data` 子文件夹。

## 3. 悬浮球怎么用

- **单击**：在程序窗口内打开任务工作台。
- **按住拖动**：移动悬浮球，位置会保存。
- **右键 → 游戏统计与设置**：查看图表、调音量、配置游戏识别等。
- **右键 → 隐藏悬浮球**：保持后台计时，双击系统托盘图标可恢复。
- **关闭工作台或设置窗口**：继续计时；右键“退出”才退出工具，强警告期间需先退出游戏。

悬浮球显示剩余分钟数，额度不足时变黄、变红；超时显示 `+数字`。联动模式没有已赚额度时显示锁定标记。

## 4. 写任务、完成任务、赚时间

[拾刻工作台](https://your-workbench.chatgpt.site)可以从手机浏览器、电脑浏览器和时间球内嵌窗口打开。使用同一个获准访问的账号，读取的是同一份云端任务。

### 最快的输入方式

直接在首页输入框输入，按 **Enter** 保存：

```text
看完ros的第三课 45
复盘今天的错题 20
阅读积累 15
```

末尾空格后的数字表示：**完成这条任务后奖励多少分钟游戏时间**，不是立即到账，也不是任务预计耗时。上例第一条会保存为“看完ros的第三课”，完成后奖励 45 分钟。

也支持 `任务 +45`、`任务 45分钟`、`任务 45min`。没有末尾奖励数字时默认 15 分钟；单条奖励为 0–90 的整数，每日已赚总额度最多 90 分钟。

### 查找与批量导入

- 顶部搜索框可按任务文字、完成标准查找；电脑上按 `/` 快速聚焦搜索。
- 用日期及“全部 / 待完成 / 已完成”筛选。
- 手机端有固定的“写任务”入口。
- 点击“导入 QQ 日志”，粘贴每行一条的待办。可以写末尾奖励数字，先预览、再确认导入。工具不会登录或自动抓取 QQ。

### 完成与分享是两个操作

- 普通任务：点击任务前的方框确认完成，奖励到账；再次点击可撤销。
- 雅思核验任务：需要本机雅思教练的真实完成记录，不能只点击方框赚取。其他电脑未配置教练记录时，不会自动核验；请先联系维护者配置，或创建普通的自我确认任务。
- 已完成任务可主动“分享打卡”，确认后的文字才进入朋友圈；可以撤回分享，不影响原任务。
- 每个人的私人任务、奖励和游戏记录不会因为完成任务就自动公开。

## 5. 把工作台连接到这台电脑

获得网站访问权限后：

1. 单击悬浮球，在内嵌工作台中登录自己的账号。
2. 请站点维护者为这台电脑准备受保护网站所需的本机后台访问授权。**分享包不附带原作者的授权凭据。**
3. 点击窗口顶部的“连接本机时间球”，创建并保存自己的设备连接。也可在网站“我的设置”创建设备密钥，再到“游戏统计与设置 → 任务工作台配对”填写。
4. 确认时间球显示“已同步工作台”，网站也出现该电脑的最近同步时间。仅显示“设备已保存”不代表后台同步已经成功。

**网页登录、设备密钥和电脑的后台访问授权是不同环节。** 如果提示同步失败，不能只靠复制设备密钥解决；请联系站点维护者，不要借用别人的账号或复制别人的 `data` 文件夹。

成功配对后，电脑约每 30 秒同步一次额度。手机上确认任务后，通常需等待下一次同步。断网时只使用当天最近成功同步的额度；跨日未同步时按 0 处理，不会自动退回固定 90 分钟模式。

## 6. 提醒与强制警告规则

### 独立计时模式

- 每日额度 90 分钟，在 60、80、90 分钟时声音提醒。
- 每组普通提醒响 6 下，每下约 0.42 秒，两下之间停 1 秒。
- 当天累计达到 105 分钟且游戏仍在运行，出现置顶警告并持续发声。

### 工作台联动模式

- 提醒按当天已赚额度计算。比如赚到 45 分钟，就使用 45 分钟额度。
- **已赚额度为 0 时运行游戏，会立即进入强警告。** 请先完成任务、确认同步，再开始游戏。
- 有额度时，超过当前额度 15 分钟会进入强警告。例如已赚 45 分钟，额度已用达到 60 分钟时触发。

### 强警告怎样结束

请先保存进度，再退出所有被统计的游戏进程。工具确认进程退出后，弹窗与声音自动停止，通常有数秒检测延迟。

最小化游戏、切回桌面、点击关闭或按 Alt+F4 都不会解除强警告；警告跨过零点也不会自动解除。工具不会替你强杀游戏进程，也不会阻止 Windows 关机。

普通音量可在设置中调节，0% 为普通提醒静音；**强警告不随普通提醒静音关闭，音量为 0 时使用默认 30% 音量。**

## 7. 统计、识别与每周重置

- 只统计工具运行期间的游戏时间，无法补录工具关闭期间的游戏。
- 后台或最小化的游戏也计时；电脑休眠不计时。
- 多款游戏同时运行时，总时长不重复累计，各游戏平均分摊。
- 统计页有最近 7 天的“各游戏柱状图”“每日总和折线图”和明细。
- 游戏日记录按电脑本地时区分日；建议把系统时区设为北京时间，与工作台保持一致。
- 自动识别 Steam 游戏库。漏识别可选择包含 `steamapps` 的库文件夹，或手动添加实际游戏 EXE；误识别的软件、启动器可以排除。
- 游戏里建议用无边框全屏。普通桌面悬浮窗无法保证覆盖真正的独占全屏；声音提醒独立运行。

“每周一次 · 重置今日额度”清零今天用于提醒的额度已用时间，保留真实游戏历史及图表。每个北京时间自然周只能使用一次，周一零点恢复机会，重启不恢复次数。

联动模式重置不会增加已赚分钟，也不能跳过学习任务。强警告期间需先退出游戏再操作重置。

## 8. 数据与隐私

这份分享包只包含程序、微软组件及其许可文件、通用 README，**没有任何人的游戏记录、任务、登录资料、设备密钥、诊断日志或访问凭据**。

使用后生成的 `data` 文件夹属于使用者本人：

| 内容 | 用途 |
| --- | --- |
| `history.xml` / `.bak` | 游戏记录与配置；每日记录只保留今天及之前 6 天 |
| `WebView2/` | 内嵌网页登录资料及浏览器数据 |
| `workbench.dat` / `workbench-defaults.dat` | 当前 Windows 用户加密保护的本机配对 / 授权配置 |
| `diagnostics.log` | 有大小上限的本机异常与资源诊断；可能含文件路径 |

再次转发时，**发送原始分享 ZIP，不要把自己运行后的整个文件夹重新压缩**。手机和电脑的云端任务受账号及网站权限控制；本地配置不会因为文件加密就适合转发给别人。

## 9. 常见问题

**打不开工作台，提示登录或无权限？**
先用本人账号登录；若仍无权限，联系站点所有者申请邮箱邀请。包内没有公开注册或自动加入功能。

**任务完成了，但时间球没有增加分钟？**
检查是否登录同一个账号、是否完成配对、是否显示“已同步工作台”。等待下一次约 30 秒的同步；再检查是否已达每日 90 分钟上限。雅思核验任务还需要本机教练完成记录。

**网页组件启动失败，或提示找不到 DLL？**
确认完整解压了所有文件，并已安装 WebView2 Runtime；不要仅转发 EXE。查看本机 `data/diagnostics.log` 可帮助排查。某些账号登录方式也可能受内嵌浏览器策略限制，尚不能保证覆盖所有账号环境。

**悬浮球出现白底红叉或感叹号？**
可能是绘制异常，不能仅凭这个现象断定系统内存不足。当前版本会记录诊断并尝试恢复；如持续异常，退出游戏后重启工具，向维护者提供必要的日志片段，并留意日志中的本地路径隐私。

**如何设置开机启动或卸载？**
在游戏统计与设置中创建 / 取消开机启动。卸载前先取消开机启动、退出工具，再删除解压后的文件夹。移动程序位置后，需重新设置开机启动。
