# Steam 时间球 × 拾刻任务工作台

把每日任务与游戏时间联系起来：**记任务 → 完成任务赚分钟 → 时间球统计 Steam 游戏时长 → 超时提醒**。

这个仓库包含 Windows 悬浮球客户端及配套的私人云端任务工作台源码。这里没有原作者的游戏记录、学习任务、浏览器登录状态、设备密钥或部署访问令牌。公开源码不等于获得原有私人网站的访问权限。

## 功能

### Windows 时间球

- 可拖动悬浮球，显示剩余或超时分钟；单击在窗口内打开任务工作台。
- 自动识别 Steam 游戏，支持手动添加实际游戏 EXE、补充游戏库及排除误识别应用。
- 后台游戏计时，休眠不计时；同时运行多款游戏时总时长不重复累计。
- 最近 7 天的逐游戏柱状图、每日总时长折线图与明细。
- 可调音量与试听；普通提醒每组 6 下，两下间隔 1 秒。
- 超过额度 15 分钟后置顶警告并持续发声，退出游戏进程后解除。联动模式没有已赚额度时，运行游戏立即提醒。
- 每周一次重置今日额度已用，保留真实历史记录；重置不会增加任务赚取的分钟数。
- 独立模式每日固定 90 分钟；联动模式使用当天任务赚取的额度，封顶 90 分钟。

### 网页工作台

- 输入 `看完ros的第三课 45`，回车创建任务，完成后奖励 45 分钟。支持 `+45`、`45分钟`、`45min`；未指定时默认 15 分钟。
- 未完成任务可在创建当天及随后两天完成；奖励计入实际完成当天，过期任务保留历史。
- 搜索、日期和完成状态筛选；粘贴 QQ 日志批量导入，确认后保存。
- 普通任务由用户确认，雅思任务可通过本机教练完成记录核验。
- 每个人的任务私有；主动分享打卡或勾选任务发布只读规划快照，支持撤回。
- 响应式页面、手机主屏幕快捷入口、简单配色切换。
- 设备配对、撤销和额度同步；时间球只需同步额度及必要完成标记。

## 构建 Windows 客户端

需要 64 位 Windows 10 / 11 和 .NET Framework 4.6.2 或更高版本。内嵌工作台还需要 Microsoft Edge WebView2 Evergreen Runtime。

```powershell
cd desktop
.\build.ps1
.\SteamTimeBall.exe
```

程序与同目录三个 DLL 必须一起保留。SDK 依赖来自官方 NuGet 包 `Microsoft.Web.WebView2`，版本 `1.0.4314.35`；本仓库仅包含必需的 SDK 文件，不包含完整浏览器运行时。

源码里的 `https://your-workbench.chatgpt.site` 是示例地址。请替换为自己部署的工作台地址后构建，或通过本机配对配置填写自己的站点；示例地址不是可用服务。

运行本地自检：

```powershell
Start-Process .\SteamTimeBall.exe -ArgumentList '--self-test' -Wait
Get-Content .\test-results.txt
```

`--webview-smoke` 可另行检查已安装的网页运行组件，不要求登录真实账号。

## 构建、测试与预览网页

需要 Node.js 22 或更新版本。本版本无需安装 npm 依赖。

```powershell
cd web
Copy-Item .openai/hosting.example.json .openai/hosting.json
npm run build
npm test
npm run validate
npm run dev
```

本地预览地址为 `http://127.0.0.1:5179`，使用模拟账号和内存数据，页面会标明这是预览。它不连接生产数据，进程退出后预览数据消失。

发布时将示例 `project_id` 换成自己的真实 Sites 项目 ID；使用 R2 绑定 `BUCKET` 保存用户状态，沿用平台的私人访问和账号邀请机制。实际配置文件已被 Git 忽略。

**此后端依赖 Sites 网关注入可信的认证身份。不要将它当作已经自带完整认证的裸 Worker 直接发布到公网。** 若换用其他托管方式，必须先补上可信身份验证、访问白名单和请求保护，不能直接相信客户端传入的身份头。

## 配对与权限

1. 部署自己的工作台并配置谁可以访问。
2. 为客户端准备该站点支持的后台访问授权，保存在本机加密配置中。
3. 登录工作台，点击内嵌窗口的“连接本机时间球”，创建自己的设备连接。
4. 确认显示“已同步工作台”，而不只是“设备已保存”。

账号邀请、设备密钥与后台访问授权是不同环节。仅下载此源码、登录一个账号或复制设备密钥，都不代表已经获得原站点权限。请勿使用他人的账号配置。

本机敏感配置使用当前 Windows 用户的 DPAPI 加密，存放在运行后生成的 `data/` 中；浏览器登录资料位于 `data/WebView2/`。这些内容均不应进入 Git。

## 验证与限制

- 网页测试覆盖账号隔离、奖励上限、任务三天保留、北京时间跨日、主动分享及撤回、设备撤销等。
- 客户端有计时边界、提醒、周重置、绘制恢复和配对来源检查。
- 自动测试不等于已验证每种真实账号登录方式、手机、游戏或显卡环境。
- 普通桌面悬浮窗无法保证覆盖独占全屏游戏，建议使用无边框全屏。
- 工具只统计运行期间的游戏，不能补录关闭期间的时长。
- 任务完成核验有不同来源：普通任务是自我确认；雅思集成需要使用者自行配置本机教练记录，仓库不附带个人学习文件。

更详细的操作、数据位置和常见问题见 [使用指南](docs/USER_GUIDE.md)。指南中的站点地址也已替换为示例。
